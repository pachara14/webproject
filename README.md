# ระบบเช็คโปรเจกต์และเช็กชื่อเข้ามีท

ระบบเว็บสำหรับจัดการโปรเจกต์ของทีม และแสดงตาราง/กิจกรรมที่เกี่ยวข้องกับการเข้ามีทแบบอ่านง่าย ใช้งานผ่านเว็บ และรองรับการเข้าสู่ระบบด้วยอีเมลของมหาวิทยาลัย รวมถึง Google OAuth

## ภาพรวมระบบ

โปรเจกต์นี้พัฒนาด้วย Laravel สำหรับใช้เป็นศูนย์กลางในการดูข้อมูลโปรเจกต์ ตารางงาน และกิจกรรมต่าง ๆ ที่เกี่ยวข้องกับมีทหรือการนัดหมายของทีม

ระบบหลักที่มีในโปรเจกต์นี้ประกอบด้วย:

- เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- สมัครสมาชิกด้วยอีเมลมหาวิทยาลัย
- เข้าสู่ระบบด้วย Google
- หน้าหลัก Dashboard สำหรับดูข้อมูลสรุป
- หน้ารายการโปรเจกต์
- ปฏิทินแสดงกิจกรรม/กำหนดการจากตาราง `project_schedule`
- API และหน้าเว็บสำหรับดึงข้อมูลอีเวนต์ไปแสดงผลในปฏิทิน

## เทคโนโลยีที่ใช้

- PHP 8.3+
- Laravel 13
- Laravel Sanctum
- Laravel Socialite
- MySQL / MariaDB หรือฐานข้อมูลที่รองรับ Laravel
- FullCalendar สำหรับแสดงปฏิทินบนหน้าเว็บ
- Swagger / OpenAPI สำหรับเอกสาร API
- Vite สำหรับ frontend assets

## ฟีเจอร์

- ระบบสมัครสมาชิกและล็อกอินสำหรับผู้ใช้ในโดเมนมหาวิทยาลัย
- ตรวจสอบอีเมลให้ลงท้ายด้วย `@rmutr.ac.th`
- สร้าง session สำหรับใช้งานบนเว็บ
- ล็อกอินผ่าน Google และบันทึกข้อมูลผู้ใช้ลงระบบ
- ดึงรายการโปรเจกต์จากฐานข้อมูล
- แสดงกำหนดการเป็นรายการและในรูปแบบปฏิทิน
- ส่งข้อมูลอีเวนต์ในรูปแบบ JSON เพื่อเอาไปต่อยอดกับ FullCalendar

## โครงสร้างเส้นทางหลัก

- `/` หน้าเข้าสู่ระบบ
- `/login` หน้าเข้าสู่ระบบ
- `/register` หน้าสมัครสมาชิก
- `/dashboard` หน้าแดชบอร์ด
- `/auth/google` เริ่มเข้าสู่ระบบด้วย Google
- `/auth/google/callback` callback จาก Google
- `/events` หน้ารายการกำหนดการโปรเจกต์
- `/calendar/events` API สำหรับดึงข้อมูลอีเวนต์
- `/myproject` หน้ารายการโปรเจกต์ของฉัน

## ความต้องการระบบ

- PHP 8.3 หรือสูงกว่า
- Composer
- Node.js และ npm
- ฐานข้อมูล MySQL / MariaDB หรือที่ Laravel รองรับ

## การติดตั้ง

1. โคลนโปรเจกต์มาที่เครื่อง

2. ติดตั้งแพ็กเกจ PHP

```bash
composer install
```

3. ติดตั้งแพ็กเกจ frontend

```bash
npm install
```

4. สร้างไฟล์ `.env`

```bash
cp .env.example .env
```

5. สร้าง application key

```bash
php artisan key:generate
```

6. ตั้งค่าฐานข้อมูลในไฟล์ `.env`

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

7. รัน migration

```bash
php artisan migrate
```

8. สร้าง build assets

```bash
npm run build
```

## การรันโปรเจกต์

### โหมดพัฒนา

```bash
php artisan serve
```

ถ้าต้องการรัน frontend แบบ watch:

```bash
npm run dev
```

### รันแบบรวม

ใน `composer.json` มีสคริปต์สำหรับโหมดพัฒนาอยู่แล้ว:

```bash
composer run dev
```

คำสั่งนี้จะรัน:

- Laravel server
- queue listener
- log viewer
- Vite dev server

## โครงสร้างข้อมูลที่เกี่ยวข้อง

โปรเจกต์นี้อ้างอิงตาราง `project_schedule` สำหรับเก็บข้อมูลกำหนดการ เช่น:

- `title`
- `description`
- `lecturer`
- `note`
- `start_date`
- `end_date`
- `color`

## หมายเหตุการใช้งาน

- ระบบล็อกอินรองรับเฉพาะอีเมลที่ลงท้ายด้วย `@rmutr.ac.th`
- ถ้ายังไม่มีรูปโปรไฟล์จาก Google ระบบจะบันทึกเป็นข้อมูลจากบัญชีผู้ใช้
- ข้อมูลปฏิทินถูกส่งออกในรูปแบบ JSON เพื่อเชื่อมกับ FullCalendar ได้ทันที

## สคริปต์ที่มีในโปรเจกต์

- `composer run dev` สำหรับโหมดพัฒนา
- `composer run test` สำหรับรันชุดทดสอบ
- `composer run setup` สำหรับติดตั้งและเตรียมโปรเจกต์แบบอัตโนมัติ
